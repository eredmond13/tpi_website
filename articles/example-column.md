This is a **placeholder column**. It exists so the Signals page has something to
show, and so you can see how a longer piece reads before writing a real one.
Delete this file, or write over it, whenever you like.

A column is set apart from the shorter notes. Its headline runs larger, its
photograph runs as a wide banner, and the text here sits in a narrower measure
so it reads as a column rather than as a web page. The only thing that makes it
a column is the `format: column` line at the top. Remove that line and this
becomes a note.

## Subheadings work like this

Start a line with two hashes. Use them sparingly in a piece of this length.

Paragraphs are separated by a blank line. **Bold** uses two asterisks either
side, *italic* uses one, and a link looks like
[this](https://publicpolicy.cornell.edu/btpi/).

> A quotation sits behind a right angle bracket, which is useful for a line
> from a document or an official statement.

A column has no PDF attached. If a piece needs one, it belongs on the
publications page instead.
